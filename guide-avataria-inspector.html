Avataria Safe Inspector V12

Guide local d'utilisation — fichier autonome, sans serveur, sans CDN, sans connexion internet.

Version du guide : • Script : • Généré le .

Ouvrez ce fichier par double-clic (file:///...), puis utilisez les exemples directement dans la console du jeu. Le guide démarre en mode simple : nettoyage, déplacement et téléportation. Passez en mode expert pour afficher les captures.

Guide simple : nettoyer et se déplacer

Ce mode utilisateur évite volontairement toute la partie capture/analyse. Il se concentre sur les actions utiles en jeu : aller sur une map, nettoyer les déchets et déplacer l'avatar.

1. Aller dans la cour
__AVA_GO_YARD__();
2. Vérifier le cleaner
__AVA_MAP_CLEANER__.status();
3. Nettoyer automatiquement
__AVA_MAP_CLEANER__.start({
    maps: ["garbage"]
});

Routine conseillée

  1. Ouvrez le jeu et attendez que la map soit chargée.
  2. Collez __AVA_GO_YARD__(); si vous n'êtes pas dans la cour.
  3. Lancez le nettoyage avec __AVA_MAP_CLEANER__.start({maps:["garbage"]});.
  4. Surveillez les logs [AVA CLEANER].
  5. Utilisez pause() si vous voulez laisser l'action en cours finir puis arrêter les suivantes.
  6. Utilisez stop() avant de recharger la page.
__AVA_MAP_CLEANER__.pause();
__AVA_MAP_CLEANER__.resume();
__AVA_MAP_CLEANER__.stop();

Boucle automatique ON/OFF

Le vrai réglage par défaut se trouve au début du userscript : AVA_AUTO_CLEAN_LOOP_ON. Mettez-le à true pour lancer automatiquement la boucle à chaque chargement, ou à false pour l'ignorer. Les durées se règlent au même endroit avec AVA_AUTO_CLEAN_LOOP_FULL_THEN_YARD_MS, AVA_AUTO_CLEAN_LOOP_YARD_THEN_FULL_MS, AVA_YARD_MAX_RETRIES_PER_OBJECT pour le nombre d’essais Yard avant reload, et AVA_YARD_INTERACTION_TIMEOUT_MS pour le délai avant de considérer un ramassage Yard bloqué.

// Au début du userscript :
const AVA_AUTO_CLEAN_LOOP_ON = true;
const AVA_AUTO_CLEAN_LOOP_FULL_THEN_YARD_MS = 40 * 60 * 1000;
const AVA_AUTO_CLEAN_LOOP_YARD_THEN_FULL_MS = 30 * 60 * 1000;
const AVA_BUTTERFLY_MAX_ATTEMPTS = 3;
const AVA_YARD_MAX_RETRIES_PER_OBJECT = 1;
const AVA_YARD_INTERACTION_TIMEOUT_MS = 40000;
__AVA_AUTO_CLEAN_LOOP__.status();
__AVA_AUTO_CLEAN_LOOP__.off();

Déplacement manuel simple

Les coordonnées utilisent x horizontal et y vertical. Cette commande fonctionne seulement quand l'avatar et le constructeur de marche ont été capturés par le script.

__AVA_WALK_TO__(44, 20);

Si le cleaner touche un mauvais objet

Ajoutez un mot-clé d'exclusion. La comparaison ignore les majuscules/minuscules et regarde l'identifiant, la classe et le type.

__AVA_MAP_CLEANER__.start({
    maps: ["garbage"],
    excludedKeywords: ["sit", "chair", "bench"]
});

Installation et démarrage rapide

  1. Activer le userscript dans Tampermonkey.
  2. Ouvrir le jeu Avataria.
  3. Attendre le chargement complet et le message [AVA-V12].
  4. Ouvrir les outils de développement puis l'onglet Console.
  5. Vérifier que les fonctions globales sont présentes.
Object.keys(window)
    .filter(key => key.startsWith("__AVA_"))
    .sort();
typeof window.__AVA_MAP_CLEANER__
// Résultat attendu : "object"
Si une fonction vaut undefined, rechargez la page du jeu et attendez la fin du chargement.

Ouvrir la console du navigateur

Raccourcis courants : F12, Ctrl + Shift + I, ou Ctrl + Shift + J.

Certains navigateurs bloquent temporairement le collage dans la console. Suivez l'avertissement affiché pour cette session uniquement ; ne désactivez pas durablement les protections.

Capturer des informations

Utilisez une capture par action : cliquer un objet, se déplacer, changer de map, ouvrir un inventaire, acheter, placer un meuble, envoyer un message ou nettoyer un déchet.

  1. Vider ou démarrer une capture propre.
  2. Effectuer une seule action dans le jeu.
  3. Arrêter la capture.
  4. Afficher les résultats.
  5. Copier/exporter si nécessaire.
__AVA_NET_START__("test-action");
__AVA_ACTION_START__("test-action");
__AVA_UI_START__("test-action", 8000);
// Faites une seule action dans le jeu.
__AVA_UI_STOP__();
__AVA_ACTION_STOP__();
__AVA_NET_STOP__();
__AVA_NET_LIST__();
__AVA_ACTION_LIST__();
__AVA_UI_LIST__();

Pour les objets métier de type service (ex. déchets), ajoutez :

__AVA_SERVICE_START__("yard-object");
// Cliquez un objet.
__AVA_SERVICE_STOP__();
__AVA_SERVICE_LIST__();
const obj = __AVA_SERVICE_LAST__();
obj?.objectId;
obj?.shopItem?.typeId;

Captures WebSocket

Le script intercepte les trames SEND et RECV. SEND correspond aux messages envoyés par le client ; RECV aux réponses du serveur.

Une action visible peut générer plusieurs trames. Ne supposez jamais qu'un clic correspond à un seul message.
__AVA_NET_START__("one-click");
// Faites une seule action.
__AVA_NET_STOP__();
__AVA_NET_LIST__();
__AVA_NET_SHOW__(0);

Historique brut réellement disponible : window.__AVA_V11.wsFrames.

window.__AVA_V11.wsFrames.slice(-10);
window.__AVA_V11.wsFrames.filter(frame => frame.direction === "SEND").slice(-10);
copy(JSON.stringify(window.__AVA_V11.wsFrames, null, 2));
window.__AVA_V11.wsFrames.length = 0; // vider l'historique brut

Export résumé des traces réseau :

__AVA_NET_COPY__();

Capturer une action du jeu

Différences utiles :

  • Réseau : trames et pile d'appels autour de WebSocket.send.
  • Action : fonctions métier vues dans la pile d'appels.
  • Service object : objets avec objectId et shopItem.typeId.
  • Déplacement : points capturés via WalkAction.
  • Interface : événements OpenFL filtrés (clics, mouse/touch/pointer).
__AVA_ACTION_START__("inspect-action");
// Faites l'action.
__AVA_ACTION_STOP__();
__AVA_ACTION_LIST__();
__AVA_ACTION_SHOW__(0);

__AVA_ACTION_SHOW__(index) affiche la fonction, les arguments, le code source capturé et les références brutes. __AVA_ACTION_TEST__(index) existe, mais il appelle la fonction sans contexte : utilisez-le seulement pour diagnostic.

Rejouer une action

Le replay réellement disponible dans ce userscript concerne les déplacements enregistrés, pas les paquets WebSocket ni les fonctions métier arbitraires.

// Enregistrer une marche
__AVA_RECORD_START__();
// Déplacez l'avatar plusieurs fois.
__AVA_RECORD_STOP__();
__AVA_RECORD_LIST__();

// Rejouer la séquence à vitesse normale
__AVA_REPLAY_SEQUENCE__(1);

// Stopper les timers de replay manuellement si besoin
window.__AVA_V11.replayTimers.forEach(clearTimeout);
window.__AVA_V11.replayTimers.length = 0;
window.__AVA_V11.replaying = false;
Une référence JavaScript vers un objet du jeu peut devenir invalide après un changement de map ou un rechargement.

Déplacements et téléportations

x = position horizontale, y = position verticale. Selon le contexte, les coordonnées peuvent représenter la position d'un objet, celle de l'avatar, un point d'interaction ou une destination.

__AVA_WALK_TO__(44, 20);
__AVA_RECORD_START__();
__AVA_RECORD_STOP__();
__AVA_RECORD_LIST__();
__AVA_REPLAY_SEQUENCE__(1.5);

Téléportations de travail disponibles :

__AVA_LIST_DESTINATIONS__();
__AVA_GO_WORK__("garbage");
__AVA_GO_YARD__();
__AVA_GO_GARDEN__();
__AVA_GO_RESTAURANT__();
__AVA_GO_SCHOOL__();

Des commandes __AVA_GO_<DESTINATION>__() sont générées automatiquement après chargement de workManager.FYl.

Retour à la maison

Lorsque le script observe votre maison, il mémorise automatiquement ownerId, roomId et roomKey. Les commandes retournent une Promise : attendez-la pour continuer seulement après le chargement de la maison et, si demandé, de la pièce.

await __AVA_GO_HOUSE__(ownerId, roomId);
await __AVA_RETURN_HOME__();

Première utilisation : ouvrez votre maison au moins une fois afin que __AVA_RETURN_HOME__() puisse enregistrer son propriétaire et sa pièce.

Inspecter les objets

Informations utiles : objectId, className, typeId, position, getInteractPoint, startInteraction, finishInteraction, readyInteract, canAddToQueue.

__AVA_MAP_CLEANER__.inspectCandidates();
__AVA_MAP_CLEANER__.listDetectedTypes();
const rows = __AVA_MAP_CLEANER__.inspectCandidates();
const accepted = rows.filter(row => row.accepted);
accepted[0]?.rawObject;
// Exemple de résumé attendu
{
    objectId: "garbage19",
    className: "GarbageObject",
    typeId: "gbTrash",
    position: "44,20"
}

Pour inspecter un objet service capturé par clic :

__AVA_SERVICE_SHOW__(0);
const obj = __AVA_SERVICE_LAST__();
Object.getOwnPropertyNames(obj);
Object.getOwnPropertyNames(Object.getPrototypeOf(obj));

Interaction avec un objet

Pour un usage simple, utilisez __AVA_MAP_CLEANER__ : il trouve les objets nettoyables et lance l'interaction avec l'avatar capturé.
  1. Trouver une cible avec inspectCandidates().
  2. Vérifier objectId, className, typeId et position.
  3. Configurer exclusions/filtres.
  4. Lancer le cleaner ou limiter maps à la map voulue.
  5. Contrôler les logs.
const candidates = __AVA_MAP_CLEANER__.inspectCandidates();
candidates.filter(row => row.accepted).map(row => ({
    objectId: row.objectId,
    className: row.className,
    typeId: row.typeId,
    position: row.position,
    rawObject: row.rawObject
}));

Boucle automatique yard + garden / yard seul

__AVA_AUTO_CLEAN_LOOP__ démarre automatiquement seulement si AVA_AUTO_CLEAN_LOOP_ON vaut true au début du userscript. Elle attend que le jeu soit jouable sans lancer de watchdog de démarrage, nettoie d'abord ["garbage", "garden"], attend AVA_AUTO_CLEAN_LOOP_FULL_THEN_YARD_MS, recharge pour nettoyer seulement ["garbage"], puis attend AVA_AUTO_CLEAN_LOOP_YARD_THEN_FULL_MS avant de recommencer le cycle complet. Si l’iframe plante pendant cette attente, le watchdog VK diffère le rechargement jusqu’au prochain cycle au lieu de relancer immédiatement le jeu.

// Au début du userscript :
const AVA_AUTO_CLEAN_LOOP_ON = true;
const AVA_AUTO_CLEAN_LOOP_FULL_THEN_YARD_MS = 40 * 60 * 1000;
const AVA_AUTO_CLEAN_LOOP_YARD_THEN_FULL_MS = 30 * 60 * 1000;
const AVA_BUTTERFLY_MAX_ATTEMPTS = 3;
const AVA_YARD_MAX_RETRIES_PER_OBJECT = 1;
const AVA_YARD_INTERACTION_TIMEOUT_MS = 40000;
__AVA_AUTO_CLEAN_LOOP__.status();
__AVA_AUTO_CLEAN_LOOP__.off();
__AVA_MAP_CLEANER__.start({
    maps: ["garbage"],
    detectionMode: "hybrid",
    targetSelectionMode: "nearest",
    allowedClasses: ["GarbageObject"],
    allowedTypeIds: ["gbTrashEnrg"],
    garbageKeywords: ["garbage", "trash", "rubbish", "waste", "gbtrash"],
    excludedClasses: [],
    excludedTypeIds: [],
    excludedObjectIds: [],
    excludedKeywords: ["sit"],
    temporaryUnavailableDelay: 1500,
    fullRescanInterval: 1000,
    interactionTimeout: 40000,
    scanDelay: 500,
    emptyScansRequired: 3,
    emptyScanInterval: 1000,
    mapLoadTimeout: 30000,
    mapStableMs: 2500,
    maxRetriesPerObject: 3,
    worldScanDepth: 5,
    maxWorldScanObjects: 6000
});

Priorisation des déchets proches

Avec targetSelectionMode: "nearest", le cleaner calcule la distance² depuis l'avatar. Il privilégie le point d'interaction renvoyé par getInteractPoint, puis la position de l'objet en fallback. Les cibles sans coordonnées restent valides mais passent après les cibles positionnées.

[AVA CLEANER] Next target: garbage19|gbTrash|44,20 at 44,20, distance²=25

Exclusion par mots-clés

excludedKeywords est comparé sans tenir compte de la casse avec objectId, className et typeId.

__AVA_MAP_CLEANER__.start({
    maps: ["garbage"],
    excludedKeywords: ["sit", "chair", "bench"]
});
// sitItem10 est ignoré car son identifiant contient "sit".

Dépannage

La fonction est undefined

  • Le userscript est-il activé ?
  • La page a-t-elle été rechargée ?
  • Le jeu a-t-il fini de charger ?
  • La console est-elle dans le bon contexte ?

Aucun avatar capturé

Une action ou un changement de map peut être nécessaire pour que le hook LocationAvatar.addAction capture window.__AVA_CURRENT_AVATAR__.

Aucun objet détecté

Vérifiez la map actuelle, detectionMode, les exclusions, les mots-clés exclus, les classes/typeId autorisés et le chargement complet.

Une action est rejouée plusieurs fois

Arrêtez les timers de replay, videz les anciennes captures et ne conservez qu'une action par capture.

window.__AVA_V11.replayTimers.forEach(clearTimeout);
window.__AVA_V11.replayTimers.length = 0;

Le cleaner sélectionne un meuble

Ajoutez un mot dans excludedKeywords, par exemple chair, bench ou lamp.

Le cleaner ne trouve pas tous les déchets

Utilisez inspectCandidates() et listDetectedTypes() pour voir les variantes rejetées ou détectées.

Le cleaner reste bloqué sur des objets fantômes

Le script ignore maintenant les cibles durablement indisponibles après plusieurs scans ou plusieurs secondes. Vérifiez __AVA_MAP_CLEANER__.status() pour voir pendingTargets et inactiveTargets.

Bonnes pratiques

  • Faire une seule action pendant une capture.
  • Toujours vérifier la cible avant une interaction.
  • Vider les anciennes captures avant un nouveau test.
  • Ne pas lancer plusieurs cleaners en parallèle.
  • Arrêter le cleaner avant de recharger la page.
  • Recharger la page après une mise à jour du userscript.
  • Copier les logs utiles avant de fermer la console.
N'injectez pas de trames WebSocket et ne rejouez pas des paquets à l'aveugle. Ce guide documente les outils présents dans le userscript.
